# Eremex Designer Plugin

This adapter targets `Eremex.Avalonia.Controls` and `Eremex.Avalonia.Themes.DeltaDesign` version `1.0.98`, which is the verified compatible line for the current .NET 6 / Avalonia 11.1 host.

The plugin is intentionally limited to `TextEditor` in the first release. It does not redistribute Eremex: use a valid Eremex trial or license and accept the vendor EULA before restoring generated projects.
